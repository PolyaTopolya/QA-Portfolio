# BUG-A1001: Сохранение даты рождения из будущего в профиле Twinby Web

- **Проект:** Сайт знакомств "Twinby" (Web)
- **Версия:** Twinby Web v.19.5.3
- **Окружение:** Safari 26.5.2
- **Severity:** Major | **Priority:** Medium
- **Статус:** Open

## Описание
При редактировании профиля поле «Дата рождения» позволяет выбрать дату из будущего (например, 2030 год) и сохраняет её без ошибки, хотя по требованиям возраст пользователя должен быть не менее 18 лет.

## Предусловия
1. Браузер Safari на устройстве.
2. Пользователь авторизован на https://twinby.ru/.
3. Перешел в раздел "Настройки" → "Редактирование профиля".
4. Поле "Дата рождения" активно.

## Шаги воспроизведения
1. Нажать на поле "Дата рождения".
2. Выбрать в календаре дату из будущего (например, 28 июля 2030 года).
3. Нажать кнопку "Сохранить".
4. Обновить страницу или повторно открыть профиль.

## Ожидаемый результат
При выборе даты, соответствующей возрасту < 18 лет, появляется ошибка "Вы уверены? Пожалуйста, проверьте год рождения", кнопка "Подтвердить" неактивна.

## Фактический результат
Дата сохраняется успешно, ошибка не отображается, профиль обновляется с некорректной датой.

## Примечания
Баг воспроизводится стабильно (5/5 попыток).
